# Cyber Security Website Style Guide

## Recommended Design Direction
A **dark theme with a subtle glassmorphism style** works well for a cyber security company because it feels modern, secure, technical, and premium. The glass effect should be used lightly on cards, panels, and navigation areas rather than across the full page.

---

## Core Colour Palette

### Primary Backgrounds
- **Deep Midnight:** `#050816`
- **Dark Navy:** `#0B1120`
- **Section Background:** `#0F172A`
- **Card Background:** `#111827`

### Glass / UI Layers
- **Glass Surface:** `rgba(255, 255, 255, 0.08)`
- **Glass Border:** `rgba(255, 255, 255, 0.18)`
- **Soft Glow Border:** `rgba(0, 194, 255, 0.25)`

### Accent Colours
- **Electric Blue:** `#00C2FF`
- **Cyan Blue:** `#00D1FF`
- **Security Green:** `#00E6A7`
- **Violet Highlight:** `#7C3AED`

### Text Colours
- **Primary White:** `#FFFFFF`
- **Soft White:** `#F9FAFB`
- **Muted Text:** `#B6C2CF`
- **Secondary Muted:** `#94A3B8`

### Alert / Status Colours
- **Danger / Critical:** `#FF4D6D`
- **Warning:** `#F59E0B`
- **Success:** `#10B981`

---

## Best Font Pairing

### Headings
- **Sora**
- Alternative: **Space Grotesk**

Why: These fonts look clean, modern, futuristic, and premium without losing readability.

### Body Text
- **Inter**
- Alternative: **Manrope**

Why: These fonts are highly readable for SaaS, tech, and enterprise websites.

---

## Recommended Font System
- **H1 / Hero Heading:** Sora Bold
- **H2 / Section Heading:** Sora SemiBold
- **Body Text:** Inter Regular
- **Buttons / Labels:** Inter Medium
- **Small UI Text:** Inter Regular

---

## Suggested Usage
- Use `#050816` or `#0B1120` for the main background.
- Use `#111827` or glass panels for cards and feature blocks.
- Use `#00C2FF` as the main CTA and highlight colour.
- Use `#00E6A7` only for positive indicators, secure states, or small accents.
- Use `#FFFFFF` for headings and `#B6C2CF` for paragraph text.
- Keep blur effects subtle and avoid overusing transparency.

## Final Recommendation
For a cyber security company website, the strongest combination is:

- **Theme:** Dark
- **Style:** Subtle glassmorphism
- **Heading Font:** Sora
- **Body Font:** Inter
- **Primary Accent:** Electric Blue
- **Support Accent:** Security Green

This gives the website a trustworthy, premium, and advanced cyber security look.
